# Python для новичка — рабочая папка

Python 3.13.17 установлен. Здесь лежат файлы с задачами: в каждом файле задание в комментариях и заготовка кода.

## Как запускать

**Способ 1 — в один клик (самый простой).**
Двойной клик по ярлыку **«Запустить задачу»** на рабочем столе → введи номер файла (например `1`) → программа запустится, окно останется открытым.

**Способ 2 — из терминала в этой папке:**

```powershell
.\run.ps1 task_01_hello.py
```

Или просто скажи мне «запусти task_05_temperature.py» — я запущу и покажу вывод.

> Если PowerShell ругается на запуск скриптов, выполни один раз:
> `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`

1. Решай по одной задаче, не подглядывая.

4. Присылай мне код, если застрял больше 15 минут.
